## Original design decisions

The portfolio uses an editorial hierarchy with a large headline, asymmetrical project presentation, varied section layouts, soft corners used selectively, and a muted green/ivory palette. The demo preview uses a small CSS illustration rather than an external image. The design prioritizes a transition profile and clearly distinguishes verified experience, ongoing learning, and fictional demonstrations.

## Visual QA status

The CSS includes responsive layouts and reduced-motion support. A live browser review at desktop and mobile sizes remains pending until the Next.js development server can be installed and started.
