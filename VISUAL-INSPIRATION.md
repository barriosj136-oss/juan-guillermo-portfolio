## Original design decisions

The portfolio uses an editorial hierarchy with a large headline, asymmetrical project presentation, varied section layouts, soft corners used selectively, and a white, charcoal, and blue palette. The demo preview uses a small CSS illustration rather than an external image. The design prioritizes a transition profile and clearly distinguishes verified experience, ongoing learning, and fictional demonstrations.
